# caju

Nome curto do CLI do [Caju Motion](https://github.com/MardelAraujo/caju_motion) (vídeo por código + timeline visual).
Este pacote só repassa para [`@caju-motion/cli`](https://www.npmjs.com/package/@caju-motion/cli).

```bash
npm create caju@latest meu-video   # novo projeto (recomendado)
npx caju studio                    # abre o Caju Studio na pasta atual (projects/)
npx caju doctor                    # diagnostica Node, FFmpeg, navegador, Studio…
npx caju skills add --agents all   # skills para agentes (Claude Code, AGENTS.md)
npx caju render <id>               # exporta MP4
```

Short name for the Caju Motion CLI: `npx caju --help` lists every command.
