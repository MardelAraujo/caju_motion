## Clean room

O Caju Motion é uma implementação clean-room. A API do runtime se inspira em ideias públicas de projetos como o Remotion, mas **nenhum código do Remotion é usado ou derivado**, porque a licença dele proíbe. Contribuições seguem a mesma regra.

Fontes e mídias que você coloca nos projetos mantêm as próprias licenças. Confira se as fontes da marca permitem embutir e redistribuir antes de versioná-las.
